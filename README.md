# Movie Recommendation System using Machine Learning

## Project Overview
This project is a Machine Learning-based Movie Recommendation System that recommends similar movies based on user preferences. The system uses content-based filtering techniques with TF-IDF vectorization and cosine similarity to find and suggest relevant movies.

---

## Features
- Movie recommendation based on similarity
- Content-based filtering approach
- Data preprocessing and feature extraction
- Fast similarity calculation using cosine similarity
- Beginner-friendly machine learning project

---

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- TF-IDF Vectorizer
- Cosine Similarity
- Jupyter Notebook

---

## Dataset
The dataset contains movie-related information such as:
- Movie titles
- Genres
- Keywords
- Cast
- Overview

Dataset file used:
- `movies.csv`

---

## How It Works
1. Data preprocessing is performed on the movie dataset.
2. Important textual features are combined.
3. TF-IDF Vectorization converts text data into numerical vectors.
4. Cosine Similarity is calculated between movies.
5. Similar movies are recommended based on user input.

---

## Project Workflow
- Data Collection
- Data Cleaning
- Feature Engineering
- Text Vectorization
- Similarity Calculation
- Recommendation Generation

---

## Sample Output
The system recommends movies similar to the movie entered by the user.
